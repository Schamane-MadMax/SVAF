# SVAF – Semantic Video Analysis Format (deutscher Einstieg)

Die maßgebliche Projektbeschreibung steht im englischen [README](README.md).

Kurz gesagt: SVAF ist ein audio-first, event-basiertes Format, das Video- und
Audioinhalte in durchsuchbare, speichereffiziente und RAG-taugliche
Wissensrepräsentationen überführt — Transkripte mit Wort-Timing, semantische
Events, Sprecher-Tracks, pseudonyme Identitäten und Folien samt OCR statt
vollständiger Videoframes.
